# XriAura - Telegram Mini App

Welcome to the official GitHub repository for **XriAura**, a dynamic Telegram Mini App featuring live real-time configuration control, arcade games, lucky spin wheel, tasks, and wallet management powered by Firebase Realtime Database.

## Features
- **Centralized Admin Dashboard:** Real-time synchronization of app announcements, limits, and settings.
- **Earn Hub:** Interactive Arcade Games and Lucky Spin with dynamic limits.
- **Profile & Wallet:** User verification via Telegram WebApp, bio keyword tasks, community hubs, and withdrawal settings.
- **Tech Stack:** HTML5, CSS3, JavaScript, Telegram WebApp SDK, and Firebase Realtime Database (Compat).

## Project Structure
- `index.html` - Main entry and dashboard
- `earn/` - Earn hub, arcade, and lucky spin
- `tasks/` - Daily and special tasks
- `refer/` - Referral system
- `profile/` - Profile, wallet, community, and admin control center
